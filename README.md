# ASIR / En marcha

Agenda estática de entregas, retos e historial de ASIR 1.º (curso 2026–27), junto a un calendario semanal de clases. Los entregables se ordenan desde la fecha más próxima y los completados pasan a **Entregados**.

## Uso

- Abre `index.html` en un navegador o sirve esta carpeta con un servidor estático.
- Marca entregables completados, filtra por estado y añade entregables con **Añadir entregable**.
- Los estados y las tareas añadidas se guardan en `localStorage` del navegador.
- Para incorporar entregables nuevos, actualiza `app.js` y vuelve a copiar `index.html`, `styles.css` y `app.js` a `dist/`.

Las fechas provisionales se muestran como **Por confirmar**; no se convierten en definitivas sin una fuente clara.
